AllSafe Console v9.1

One console. Every exposure surface.
Public endpoints included.

The AllSafe operator console binds your WAF, token handoffs, log stream and diagnostics into a single pane. Every endpoint below is live and reachable — by you, and by anyone who can read a URL.

Live API surface

All endpoints are unauthenticated by design. Convenience over ceremony.
GET /api/health

Service health

Liveness + build id. The thing our status page is populated from, mostly.

GET /api/token

Sentinel collector handoff

Issues a working internal collector token for trial tenants. Rotation disabled for filler keys.

GET /api/diagnostics

Diagnostics core

Public engine telemetry with declared capability claims. Part of the SOC training kit.

GET /api/logs

Audit trail

Tail of the operator request log. Read-only, unfiltered, very much public.

GET /api/agent-install

Edgeless runtime bootstrap

Auto-provisions a deployable agent bundle for new fleet nodes. One click, no consent prompts.

Operator note: the console assumes good faith. Probe depth is throttled but not blocked. If you must inspect internals, the request log tells you who already did.
